Design a modern and interactive educational web platform called **SkyLang**, a system that teaches **technical English for nursing students**.

The platform should look **innovative, educational, interactive, colorful, and engaging**, designed for students between **16 and 40 years old**.

Use a **dashboard style interface with a floating sidebar navigation**, modern cards, rounded corners, smooth shadows, and progress indicators.

The design should feel like a mix of **Duolingo + Coursera + modern SaaS dashboard**.

---

COLOR PALETTE

Primary colors:

* White (#FFFFFF)
* Light Blue (#4DA6FF)
* Black (#111111)

Secondary colors:

* Soft blue backgrounds
* Light gray cards
* Green accents for success and progress

The interface must feel **clean, modern, and friendly for learning**.

---

PLATFORM TYPE

Responsive educational web platform for:

* laptops
* mobile devices

1. Student (Aprendiz)

3. Admin

Sidebar navigation should include:

* Dashboard

* Progress

---

RAPS STRUCTURE

The system is divided into learning levels called **RAPS**.

Create 4 example RAP cards:

RAP 1 – Basic Nursing English
RAP 2 – Patient Interaction
RAP 3 – Clinical Communication
RAP 4 – Medical Documentation

Each RAP card includes:

* title
* difficulty level
* progress bar
* start button
* lock icon if not unlocked

Important rule:

RAP 2 is locked until RAP 1 is completed with excellence.

---

MODULE STRUCTURE

When clicking a RAP, display modules.

Example for RAP 1:

Module 1 – Present Simple in Medical Context
Module 2 – Present Continuous in Patient Care
Module 3 – Medical Vocabulary
Module 4 – Hospital Areas
Module 5 – Giving Directions in a Hospital

Each module card should include:

* module title
* progress indicator
* start module button
