Design an **interactive, modern and visually rich educational platform UI** called **SkyLang**, a system that teaches **technical English for nursing students**.

The design must feel **premium, elegant, playful, and interactive**, avoiding generic e-learning styles like Open English.

The interface should feel similar to modern SaaS learning platforms with **smooth animations, micro-interactions, floating elements, gradients, and dynamic dashboards**.

Use a mix of **glassmorphism, soft gradients, floating cards, and animated progress indicators**.

---

COLOR SYSTEM

Primary colors:

White #FFFFFF
Light Blue #4DA6FF
Black #111111

Secondary accents:

Soft gradient blues
Light gray cards
Green for achievements and progress

Backgrounds should use **soft gradients and subtle medical patterns**.

Create a **premium login experience**, not a simple form.

Layout idea:

Split screen layout.

Left side:

Animated illustration of a nurse interacting with medical icons (heartbeat line, hospital cross, stethoscope).

Right side:

Elegant floating login card.

Login card includes:

* SkyLang logo
* Welcome message: "Welcome back to SkyLang"
* Email field
* Password field

* Register link

* floating medical icons
* soft background gradient movement
* button hover effects
